# Feature inventory

## MVP — required
- Guest mode with nickname (no account required for initial play)
- Optional simple icon avatar
- Five-region map and progression
- Single-choice, multi-select, short-answer, and guided essay/creation question types
- Question/choice shuffling where safe; stable answer mapping
- Immediate right/wrong feedback and explanation
- Points, XP, stars/coins, streak, collectible reward
- Progress indicator and end-of-run summary
- Review incorrect answers
- Sound effects and mute toggle
- Responsive UI and accessible tap/keyboard interactions

## Phase 2 — account and cloud features
- Google sign-in (opt-in)
- Profile nickname/avatar preference
- Persisted progress, sessions, and best score
- Guest-to-account upgrade/migration, if feasible and tested
- Leaderboard (nickname only; no email/name)

## Later / optional
- Teacher dashboard, class group codes, assignments
- Create/import question packs
- Multiple subjects and grade levels
- Multiplayer or room-based quiz
- Badge collection, seasons, and class challenges

## Non-goals for MVP
- Real-money purchases or ads
- Chat or student-to-student messaging
- Competitive multiplayer
- Publicly displaying student emails or full legal names
- Strict countdown timers as a default gameplay mechanic
