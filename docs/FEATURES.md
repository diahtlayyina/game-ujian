# Feature inventory

## MVP (frontend only)
- Guest nickname and optional icon avatar
- No forced login
- Five-region adventure map
- Single choice, multi-select, short answer, guided creative response
- Feedback and explanations
- Score, progress, stars, XP, streak, collectible rewards
- Sound effects with mute
- End-of-game summary and review missed questions
- Local save using browser storage

## Optional cloud phase
- Supabase Auth (email/password or OAuth if desired)
- Profile/nickname
- Progress and best-score save across devices
- Leaderboard with nickname only

## Later
- Teacher dashboard
- Import/edit question packs
- Additional subjects and grades
- Class challenge or multiplayer rooms

## Not in MVP
- Google login
- Backend/database requirement
- Chat/social features
- Timer pressure by default
- Ads or purchases
