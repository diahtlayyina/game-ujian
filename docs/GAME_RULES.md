# Game rules and scoring (draft)

These rules are provisional; test with students and tune after prototype feedback.

## Progress
- Five regions; region 1 is open at the start.
- Completing a region unlocks the next region.
- Each region contains a balanced set of questions; content grouping will be finalized after reviewing the source bank.
- A player can retry a region. Keep a clear distinction between current run score and best score.

## Points (draft)
- Correct single-choice answer: 100 points
- Correct multi-select: 150 points (must select all correct choices and no incorrect choices; consider partial credit in later tuning)
- Short answer: 100 points if accepted; use tolerant normalization (trim, case-insensitive, punctuation/spacing) and curated accepted-answer variants
- Essay/creative response: do not auto-grade by exact text. Show a sample answer, criteria, and self-review or teacher review.
- Optional streak bonus: +20 per streak step, capped at +100 per question; avoid making streak loss feel punitive
- Explanations and retry should remain available; no harsh penalty for incorrect responses

## Rewards
- Region artifact awarded on completion
- Stars based on accuracy and completion, with thresholds to be calibrated
- XP is separate from score and used for progression/achievement display
- Coins are cosmetic/collectible; no real-money value

## Leaderboard (later)
- Nickname only
- Define whether leaderboard is weekly, class-specific, or global before launch
- Ranking should use verified best score or server-validated score; client must not be able to write arbitrary totals
- Provide opt-out or hide public nickname where appropriate
