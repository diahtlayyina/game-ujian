# Firebase setup (legacy / optional)

Firebase was the initial backend candidate, but the project direction has changed to a simpler static-first approach using plain HTML/CSS/JavaScript, GitHub, Vercel, and optional Supabase.

Firebase is not required for the current prototype. Do not continue Firebase setup unless the team later decides to switch back. The user has reported that the Game Ujian Firebase project exists and Authentication is enabled; the remaining setup was not verified.
